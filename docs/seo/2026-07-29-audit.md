# Alex Godfrey search visibility audit

**Audit date:** 2026-07-29
**Primary entity:** Alex Godfrey, software engineer
**Canonical site:** <https://www.alexgodfrey.com/>
**Target query:** `Alex Godfrey`

## Executive finding

The site has an exact-match domain and a strong technical candidate build, but Google is still seeing an older production deployment. In a US-English Google result page requested with personalization disabled (`hl=en&gl=us&pws=0`), the homepage was the eighth conventional organic result for `Alex Godfrey`. A `site:alexgodfrey.com` query exposed only the homepage and a recommendation PDF.

The dominant constraint is not keyword density. It is a combination of:

1. an undeployed technical upgrade;
2. a thin index footprint;
3. inconsistent employer/entity descriptions across the site, LinkedIn, GitHub, and employer pages; and
4. stronger independent authority for other people named Alex Godfrey.

No ethical SEO change can guarantee a permanent first position. Rankings change by location, device, query interpretation, and time. The objective is to make this Alex Godfrey the clearest and most corroborated answer for the software-engineer interpretation of the name.

## SERP interpretation

The unqualified name is ambiguous. Results above the site include an Instagram profile, IMDb entities, an Empire journalist, a McKinsey employee, Substack, and Muck Rack. The knowledge signals around the Empire journalist are especially strong because that person has years of independent editorial citations.

The useful repeated disambiguators for this site are:

> Alex Godfrey — software engineer — Cornell University — Sutter Hill Ventures / Integrated Biosciences — AI infrastructure — biotechnology — longevity — San Francisco Bay Area

Use only the employer relationship that is factually accurate and approved for public use. The site currently says Sutter Hill Ventures, while GitHub and indexed LinkedIn/employer signals emphasize Integrated Biosciences. Resolving that discrepancy is the highest-value factual decision still open.

## Effort ladder

### Low effort: minutes to two hours

1. Set the two Turnstile environment variables and deploy.

3. Use Search Console Removals for the obsolete résumé.
4. Align GitHub and LinkedIn bios and website fields.
5. If permitted, complete your `@alexgodfrey` profile on the PyLabRobot Discourse forum with the full name and canonical site.
6. Add accurate founder/author links on controlled project pages.

### Medium effort: half a day to several days

1. Resolve employer-approved public wording across company pages.
2. After permission and sanitization, publish a rigorous Echo 525/650 case study tied to PyLabRobot PR #1001; prioritize the merge and upstream documentation/release-note credit.
3. Add a small writing index when a second substantive article exists.
4. Build an original benchmark, protocol reference, or open-source artifact that others can cite.

### Higher effort: recurring work over months

1. Earn independent conference, podcast, newsletter, or alumni coverage.
2. Maintain a small cadence of original technical research rather than generic posts.
3. Build durable open-source adoption and project-level authorship.
4. Develop enough independent notability for structured public knowledge sources; do not create a self-promotional Wikipedia or Wikidata item prematurely.

## What not to do

- Do not buy links, use private blog networks, submit to bulk directories, or trade exact-match anchors.
- Do not publish high-volume generic AI-written posts.
- Do not create duplicate profile pages that compete with the homepage.
- Do not add unsupported employer, award, education, or profile schema.
- Do not treat `llms.txt` as a ranking switch. It is a retrieval convenience.
- Do not promise a date or guarantee for reaching position one.
